## 2. Deskripsi Proyek

MyAcademic merupakan website profil mahasiswa untuk menampilkan informasi akademik, daftar mata kuliah, Kartu Rencana Studi (KRS), dan rekap nilai mahasiswa. Website ini dikembangkan menggunakan HTML, CSS, dan PHP dengan penyimpanan data menggunakan array PHP tanpa database.

Website terdiri dari halaman profil mahasiswa dan halaman rekap nilai yang saling terhubung melalui navigasi. Fitur yang direncanakan meliputi konversi nilai angka menjadi huruf, status kelulusan, ringkasan total SKS, perhitungan IPS, dan filter mata kuliah berdasarkan semester.

## 3. Cara Menjalankan Website

1. Pastikan Laragon sudah terpasang di komputer.
2. Simpan folder proyek di dalam direktori `www` milik Laragon.
3. Buka Laragon, kemudian klik **Start All**.
4. Buka browser dan akses halaman `index.php` melalui localhost.
5. Klik menu Rekap Nilai dan KRS untuk membuka halaman kedua.

Alamat localhost mengikuti nama folder proyek yang digunakan.

## 4. Daftar Fitur

Fitur akan diperbarui setelah implementasi selesai.

- Profil mahasiswa — `index.php`
- Rekap nilai dan KRS — `katalog.php`
- Penyimpanan data mata kuliah — `data.php`
- Pengolahan nilai dan perhitungan akademik — `functions.php`
- Desain dan tata letak website — `style.css`
- Filter semester, konversi nilai, status kelulusan, total SKS, dan IPS — akan dihubungkan ke fungsi yang sesuai.

## 5. Fungsi Array Bawaan PHP

Fungsi array yang direncanakan untuk digunakan:

- `count()` — menghitung jumlah mata kuliah.
- `array_column()` — mengambil data dari atribut tertentu.
- `array_sum()` — menjumlahkan nilai numerik, misalnya total SKS.
- `array_filter()` — menyaring mata kuliah berdasarkan semester.
- `array_map()` — mengolah data setiap mata kuliah.

Daftar ini akan disesuaikan dengan fungsi yang benar-benar digunakan dalam kode akhir.
